# 간단 영상 편집기 · Simple Video Editor

안드로이드에서 영상을 자르고, 한글 SRT 자막을 넣어 MP4로 저장하는 무료 테스트 앱입니다.

## v0.3.1 업데이트

민트색 재생·자막 아이콘을 적용했습니다. 원형 및 둥근 사각형 홈 화면 아이콘과 테마 아이콘을 지원합니다. 기존 v0.3 위에 업데이트할 수 있습니다.

## 주요 기능

- 손가락으로 타임라인의 양쪽 손잡이를 드래그해 구간 지정
- 영상 썸네일과 선택 구간 미리보기
- SRT 자막 불러오기, 한글 CP949 인코딩 지원, 자막 싱크 조절
- 선택 구간 전체에 직접 입력한 문구 추가
- 자막을 영상에 합성하여 MP4 저장
- 저장한 영상 열기와 공유

## 사용 순서

1. **영상 선택**으로 편집할 영상을 고릅니다.
2. **자르기** 탭에서 양쪽 손잡이를 움직입니다.
3. **SRT 자막 → SRT 파일 불러오기**로 자막을 넣습니다.
4. 필요하면 **텍스트** 탭에서 문구를 입력합니다.
5. 미리보기 확인 후 **MP4로 저장**을 누릅니다.

SRT 시간은 기본적으로 원본 영상 기준입니다. 이미 잘린 영상에 맞춘 SRT라면
**자른 구간의 0초에 맞춘 SRT**를 선택하세요.

## 알아두세요

- v0.3.1은 개발용 서명으로 배포하는 테스트 버전입니다. 스토어 심사를 받은 앱은 아닙니다.
- GitHub에서 다운로드해도 외부 APK 설치 허용이 필요할 수 있습니다.
- 영상은 기기에서 처리합니다. 앱은 인터넷 권한을 요청하지 않습니다.
- 원본 파일을 수정하지 않으며 결과는 새 MP4로 저장합니다.
- 결과 영상에 자막이 영구적으로 합성됩니다.
- 저장 중 다른 앱으로 이동하면 변환이 취소될 수 있습니다.
- SRT 개별 항목의 문구·시간 수정, 여러 영상 이어 붙이기는 이번 버전에 포함되지 않습니다.
- 기기의 영상 코덱과 해상도에 따라 미리보기·변환 결과가 달라질 수 있습니다.
